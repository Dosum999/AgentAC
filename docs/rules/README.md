# 아키텍처 규칙

업무용 LLM 에이전트의 설계 규칙 모음. 각 규칙은 **규칙 / 왜(실측 근거) / 어떻게(코드 위치)** 로 적는다.

- [agent.md](agent.md) — 에이전트: 요청 흐름, 코어·도메인 분리, 컨텍스트 전파, 라우팅·감독, 도구 노출·실행, 권한, MCP, HITL, 답변 품질 가드, 컨텍스트 조립, LLM 계층, PII, 하지 말 것, 알려진 결함, 관측·평가
- [memory.md](memory.md) — 장기 메모리(4층 배치 파이프라인)

코드는 `src/agent_arch/`. 도메인 확장 지점은 `src/agent_arch/extensions.py`.
